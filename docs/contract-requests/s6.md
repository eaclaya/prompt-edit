# S6 contract requests

## 1. Drop S6's routes from the "answers 501" dataset

`tests/Feature/Foundation/RoutesTest.php` (S1-owned) asserts that `generations.index`, `generations.create`
and `generations.show` answer **501**. Once S6 implements `GenerationController`, those three rows fail
(index/create return 200; show returns 404 because the dataset's generation belongs to another user).

**Request:** split the `app routes` dataset so the 501 test only covers routes that are still stubs, or remove
the three `generations.*` GET rows from the 501 test only (keep them in the guest-redirect and
verified-email tests, which still pass).

S6's own coverage of these routes lives in `tests/Feature/Generations/**`.

## 2. Run Vitest from `make test` (and in CI)

S6 adds Vitest (`vitest.config.ts`, `npm run test:js`). `make test` (S1-owned `Makefile`) only runs Pest.

**Request:** append to the `test` target:

```make
	$(RUN) npm run test:js
```

`make ci` calls `$(MAKE) test`, so CI picks it up too.

## 3. `package.json` dev dependencies and scripts

Nobody owns `package.json`. S6 adds dev dependencies `@vue/test-utils`, `jsdom` (Vitest comes with
`vite-plus` as `vp test`) and the scripts `test:js`. Expect a trivial merge conflict with anyone else who
touches it.
