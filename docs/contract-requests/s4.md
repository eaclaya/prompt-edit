# S4 contract requests

## 1. `tests/Feature/Foundation/RoutesTest.php`: the 501 assertion for S4's routes

**Problem.** `it('answers 501 until the owning session implements the route')` runs over the whole
`app routes` dataset, including `generations.store` and `estimate`. Once S4 implements them, an
authenticated empty POST returns a validation error (302 / 422), so this S1-owned test goes red.
S3, S6 and S7 hit the same thing for their routes.

**Requested change (smallest).** Let the 501 test skip routes whose owner has landed. Either:

- (a) S4 removes `generations.store` and `estimate` from the 501 test only (a separate dataset,
  or a `->with()` filter), keeping the guest-redirect and verified-email tests for every route; or
- (b) S1 splits the dataset now so each session deletes one line.

The routes, names, URIs and middleware stay exactly as they are. No other contract change.

**Status.** Asked the coordinating session. Until answered, S4 applies (a) in its own branch so
`make test` is green, as one isolated commit that is easy to drop.
